To find the temperature in the morning, we need to add the changes to the initial temperature.

Initial temperature: 2 degrees Celsius
Temperature drop overnight: -8 degrees Celsius
Temperature increase in the morning: +3 degrees Celsius

Morning temperature = Initial temperature + Temperature drop + Temperature increase
Morning temperature = 2 + (-8) + 3
Morning temperature = 2 - 8 + 3
Morning temperature = -4 + 3
Morning temperature = -1

The answer is -1.
